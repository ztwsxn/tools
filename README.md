## ⚙️ Hướng dẫn cài đặt

1. Cài đặt tiện ích **Tampermonkey** hoặc **Violentmonkey**.
2. Chọn Userscript muốn sử dụng.
3. Nhấn **CÀI ĐẶT** để tiến hành cài đặt.
4. Xác nhận cài đặt trong trình quản lý tiện ích.
5. Truy cập trang web được hỗ trợ.
